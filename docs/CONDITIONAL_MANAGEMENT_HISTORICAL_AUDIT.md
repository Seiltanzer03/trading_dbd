# Историческая проверка ручного менеджмента

Production audit [run #2](https://github.com/Seiltanzer03/trading_dbd/actions/runs/36696646356)
завершился 30.09.2026 на exact SHA `31c9db542341d21694e1ea61c585ceb1a1215051`.
База прочитана без изменений: 208 разрешённых review. Один независимый trade
учитывается один раз для каждого правила.

| Правило | Сделки | Средняя парная разница gross R | С ненулевым эффектом | Вывод |
| --- | ---: | ---: | ---: | --- |
| `TRAIL_GAMMA_FLIP` | 4 | +0.165844 | 1 | Недостаточно наблюдений и подтверждённого якоря исполнения. |
| `SCALE_OUT_ON_SPIKE` | 9 | −0.058710 | 3 | Все три срабатывания ухудшили исход; тест измеряет касание ступени, а не отдельный spike. |
| `TIME_STOP` | 2 | 0 | 0 | Нет наблюдаемого эффекта; половина опционного горизонта не является лимитом стратегии. |

Исключены пути с интервалом наблюдений свыше пяти минут: 104 для gamma,
93 для scale/time. Дополнительно для gamma 72 review не имели более строгого
T0 уровня, для time 92 не покрывали дедлайн. Повторные review одной сделки не
увеличивают N. Внутри пути использована линейная интерполяция; gross R не
содержит проскальзывание и фактические комиссии. Ни одно правило не получает
production authority по этому отчёту, все три остаются заблокированными.

Версия аудита v2 дополнительно измеряет три заранее заданные гипотезы:

- `PROTECT_GAIN`: на T0 уже достигнут MFE >= +1R, текущая цена выше +0.5R,
  действующий стоп ниже +0.5R; переместить стоп на +0.5R.
- `PARTIAL_AT_RUNG`: дополнительно закрыть 25% остатка при первой следующей
  ступени. Это **тот же** исторический proxy, что и `SCALE_OUT_ON_SPIKE`, а не
  новый независимый опыт или обнаружение импульса.
- `EXIT_ON_THESIS_BREAK`: немедленный выход при отрицательном направленном
  soft edge, замороженном на T0. Это proxy против позиции; сам момент изменения
  тезиса между входом и T0 в этой записи не подтверждён.

Для этих гипотез также требуются фактические независимые сделки и
quant/hard-risk gate до регистрации ручной команды. Аудит только исследует,
не отправляет ордер и не создаёт действие на экране.
