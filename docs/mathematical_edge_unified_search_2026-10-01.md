## Контракты и проверка

Заранее фиксированы горизонты 15/30/60/120 минут. Признаки сохраняют existing causal contract: 13 завершённых последовательных 5m баров, только цена и UTC-время. GEX не становится самостоятельной подтверждённой головой.

Исследуются шесть отдельных бинарных целей:

| Голова | Цель |
|---|---|
| direction | Конечное направление при абсолютной конечной доходности >2bp |
| movement | Абсолютная конечная доходность >2bp |
| downside_excursion | Будущий low касается уровня T0 close × exp(−0.0002) |
| upside_excursion | Будущий high касается уровня T0 close × exp(+0.0002) |
| upper_before_lower | Верхняя 2bp граница достигнута раньше нижней; случаи без касания и касания обеих в одном 5m баре исключаются |
| early_first_touch | Первое касание любой 2bp границы приходится на завершённый бар в первой половине горизонта |

Последние четыре цели используют generic 2bp границы, не фактические стоп/тейк сделки. Время события определено с разрешением завершённого 5m бара. Порядок внутри бара не выдумывается. High/low текущего T0 бара не входят в будущие исходы.

Общие границы 40/55/70/80% фиксируются по 15m anchor timeline. Все исходы обучения завершаются до начала validation с embargo 5 минут. Горизонт выбирается по трём ранним validation блокам; финальные 20% времени не выбирают горизонт. Для path-голов условная фильтрация не меняет временные границы. Постоянная обучающая метка не считается найденным path edge.

Рабочий допуск требует положительного среднего proper-score gain в validation и test, минимум двух положительных validation и двух test блоков из трёх. Исправлено расхождение прежнего кода с документацией: две положительные validation части теперь не могут перекрыть отрицательное среднее. Публикуются log-score gain, Brier и выигрыш Brier относительно обученного baseline.

## Runtime и ограничения

`runtime_profile.path_predictions` публикует только поддержанные path-головы: вероятность, baseline, горизонт, proper-score, размер test, quality multiplier и предел эффективного веса после age/sample уменьшения. Они принадлежат тому же математическому price компоненту; несколько преобразований одной цены не дают несколько независимых голосов. Movement и раннее касание сами по себе не означают направление или приказ закрыть сделку.

Обычные direction/movement вероятности и существующие ограничения сохраняются. Новый общий механизм может использовать path-оценки при сравнении уже допустимых действий. Generic path-модель не разрешает нарушение CVaR, расширение стопа, увеличение объёма или автоматический ордер. Read-only API оставляет коэффициенты вне ответа, включая вложенные path-головы.

Proper-score и Brier измеряют качество вероятностных прогнозов. **Net PnL, CVaR результата менеджмента и польза конкретных вмешательств этим поиском не доказаны.** Для этого нужен отдельный causal replay реальных позиций с издержками. Frozen отчёт поэтому содержит `net_economic_proof=false` и `prospective_profit_proof=false`.

## Источники и воспроизведение

Свежая попытка Yahoo для всех 13 инструментов завершилась `YFRateLimitError`. Отдельная проверка публичного Binance klines вернула HTTP 451 (`Service unavailable from a restricted location`). Эти ответы сохранены в отчёте availability; не применялись обходы местоположения, синтетические котировки или предполагаемый исторический offset.

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m scripts.run_mathematical_edge \
  --sources mathematical_sources.json --captured-ts 1790878894.8216937 \
  --horizons 15,30,60,120 --output mathematical_edge_unified_search.json
```

Fresh поиск: `python -m scripts.run_mathematical_edge --output report.json --sources-output sources.json`. Provider-запросы независимы, выполняются в трёх workers с ограниченным timeout. Model fitting остаётся вне HTTP и production процесса. Read-only export сохраняет source semantics и исключает derived/offset-adjusted и незавершённые минуты.

Проверки включают неизменность причинных feature/target контрактов, исключение будущих баров, неперекрывающиеся 120m события, исключение same-bar ordering, отрицательное среднее validation, отсутствие edge на постоянных path метках, runtime/API и сохранность hard risk. Профильные проверки: 43 passed.
