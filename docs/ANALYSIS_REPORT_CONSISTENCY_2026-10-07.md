# Исправление согласованности разбора, 2026-10-07

Baseline: production main c7457dee087ef27ef8a91222a085e2dab7790ac2.
Scope: конечный пакет исправления пользовательского разбора; источники,
набор моделей/действий и hard-risk/materiality gates не расширяются.

Основной Expected/CVaR и итог всей сделки используют выбранного кандидата
единого сравнительного банка, только если выбор применён и соответствует
действующему management_decision. Итог сделки требует фактического остатка и
зафиксированного результата; отсутствующие входы не заменяются нулём.
Сохранённая bridge-экономика остаётся отдельным контролем. Независимая
консервативная проверка сохраняет свои HOLD/Δ, метод и первоначальный отказ;
Δ общей модели не отменяет её gate. Lineage quant относится к реально
использованному сравнительному банку, не к недоступным исходным траекториям.

Имена, значения и пороги метрик сохраняются при bounded compaction; бюджет
снимка не увеличен. Малый положительный вес не отображается как ноль.
Ровный вектор LLM-оценок не содержит относительного предпочтения и не получает
вес. Самооценка confidence сама по себе вес не определяет. Quality означает
принятие структурированного предпочтения, не калиброванную точность; отдельный
допуск LLM-действия показан независимо от его участия в ранжировании.
Из предоставленного текста нельзя восстановить полный вектор оценок или
точные исходные пути; причина конкретного LLM-веса не выдумывается.

Регрессии воспроизвели утрату metric и quality_basis при compaction, утрату
bridge-label финальным runtime-обработчиком и фиксируют различающиеся
экономические базы без снятия исходного отказа. Профильные Python-тесты и
frontend audit smoke пройдены. Полный mandatory CI и exact-SHA deploy являются
последующими обязательными критериями выпуска, а не результатом этого документа.

Порядок оставшейся работы сохраняет LOCKED_GLOBAL_PLAN_2026-10-07.md.
P1: receipt/materialization исправлены, регулярность требует независимого
scheduler и последовательных фактических receipts. P2: проверка готовности
существующей причинной выборки; источник или исторический факт сам по себе
не является обученной моделью, прогнозом и вкладом.

## Read-only проверка следующего пакета

Production macro status на baseline показывает сохранённые numeric CPI/NFP/
ISM строки 2/3/4/3, исторические CPI/NFP 2/2, ISM 4/2, deterministic FOMC10
и semantic valid_extractions3. Последние historical delivery BLS/ISM/FOMC
PARTIAL с HISTORICAL_OFFHOST_EXACT_SHA_MISMATCH; это не удаляет прежние строки.
Consensus feed отсутствует и блокирует surprise, но не все macro actuals,
verified reaction и novelty. Для них существующий family archive/dataset/
fixed ridge trainer/runtime adapter уже реализован. Исторические read overlays
не дописывают causal features в immutable family snapshots.

Этот status не содержит числа пригодных независимых trade cohorts, обученных
моделей и их реального вклада; число исходных строк их не доказывает.
Следующий конечный P2 criterion — один bounded просмотр существующих sample/
model artifacts по утверждённым feature routes и горизонту. Существующий trainer
требует минимум 40 независимых trade groups (20 train после purge и два OOS
блока по10), causal position/cost/outcome joins и положительный OOS MSE gain.
Непригодный sample и отсутствующий consensus имеют разные причины отказа.
Новый framework или повторное исследование без новых данных не требуется.

P1 остаётся конкретным предшествующим ограничением: status показывает OVERDUE
относительно600s, scheduler_guaranteed=false. Доступ к независимому scheduler
не подтверждён. Ручной refresh или GitHub cron не закрывает регулярность.
