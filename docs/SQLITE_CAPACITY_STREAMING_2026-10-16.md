# Потоковый замер объёма SQLite — 16.10.2026

Отдельный ограниченный шаг плана Yandex → EDE → семейства. Исходные ТЗ и
handoff не изменяются. База: принятый main11e4a09, treef8b96b89.

## Причина

Проверенная копия Yandex18,784,505,856байт восстановлена заданием38866044976.
Запрос GROUP BY/JOIN/ORDER BY по страницам не завершился за180секунд и не
сохранил распределение таблиц. Объём пригодной для переноса истории неизвестен.

## Изменение

collect_capacity последовательно читает только метаданные страниц dbstat и
суммирует их в ограниченном словаре. Нет группировки/соединения/сортировки
миллионов строк средствами SQL; сортируются только итоговые объекты.
Не более4096 измеряемых объектов и64 отображаемых строк. Лимит180секунд прежний.
Выбрана постраничная агрегация: прерывание не уничтожает уже измеренные страницы.

Полный отчёт сохраняет прежние точные allocated_object_bytes/object_count.
При таймауте или лимите объектов они остаются null. Новые observed_* поля
содержат только фактически измеренную часть, largest_objects_are_lower_bounds
указывает, что распределение неполно. В неполном отчёте64 строки описывают
измеренные объекты, а не доказанный глобальный рейтинг всех таблиц.
Разрешение на удаление данных и production_authority остаются false.

## Проверки и граница

Четыре новые регрессии сначала отказали, затем прошли: два типа прерывания,
полный результат против независимого агрегированного SQLite и лимит объектов.
Профиль восстановления/транспорта/архива/retirement:55passed,6subtests,0.82сек.
Не выполнялись полный CI, новый19ГБ restore, публикация модели, перенос строк,
освобождение production-диска или развёртывание. Быстродействие на большой
реальной копии пока не измерено. Ветка сохраняется до интеграции готового пакета.

Следующий шаг: использовать этот замер в одном off-host сеансе, сохранить
проверенную копию до выбора архивируемого объёма и проверки всех потребителей.
Только затем реализовывать и проверять перенос закрытой истории в существующий
Yandex Object Storage; резерв рабочего сервера1ГиБ сохраняется.
